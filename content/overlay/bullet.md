# Chat Bullets

Chat messages appear on the stream as scrolling bullets, similar to those found on Bilibili or Niconico TV.

Messages float across the screen and are displayed with the chatter's username.

A chatter's username and message text can be customised per-user with a [font]({{< relref "font.md" >}}), and made bold or italic with `%fontweight` and `%fontitalic`.

## Supported Emote Systems

- **7TV**: both static and animated emotes
- **Twitch**: static emotes only

Emotes are rendered inline with text in the bullet stream.

## Kiki Interaction

When [Kiki]({{< relref "kikimaki.md" >}}) reacts to a chat message, her response (kaomoji and emoji) appears directly below the bullet for a short duration.

## Clearing

[Black Silence]({{< relref "blacksilence.md" >}}) clears all active chat bullets from the screen.
