# CAPTCHAs

Random 6-character alphanumeric codes appear from time to time on the overlay.

Typing the correct code in chat claims it, awarding you with **500 points** and **+100 karma**.

A new CAPTCHA appears roughly every 30 seconds. Each code is single-use. The first chatter to type it gets the reward.

Claiming a CAPTCHA also triggers a free spin of the [gamba wheel]({{< relref "gamba.md" >}}) with the CAPTCHA item set.
